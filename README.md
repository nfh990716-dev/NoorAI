
# NoorAI

## نور الصالحي | AI DRIVER INTELLIGENCE

Drive Smarter. Earn Better.

A smart delivery driver assistant designed to analyze delivery offers, calculate operating costs, estimate net profit, and help drivers make better decisions.

### Project Goals
- Order profitability analysis
- Configurable operating expenses
- Multiple cost profiles
- Order rating engine
- Driver analytics
- Floating assistant
- Arabic and English support
